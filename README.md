# Personal-Finance-
This dashboard provides a clear overview of monthly personal finances. It tracks total income, total expenses, available balance, and compares performance to monthly income targets.

It includes key insights such as total income vs. target, income sources (main vs. side), and an alert system showing unpaid debts with their total value and month due.

**Features:**

* Interactive month filter

* Dynamic text alerts (with $ currency formatting)

* Income vs. target comparison chart

* Trend lines for income and expenses

* Built with Power BI for clear, data-driven financial insights.
